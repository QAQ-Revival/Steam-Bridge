# steam-bridge

让《明日方舟：终末地》和《鸣潮》的已有国服客户端通过 Steam 官方游戏库条目启动，无需下载完整国际服。

程序和常驻桥接进程统一叫 **`steam-bridge.exe`**。0.3.0 打包产物为 `steam-bridge-0.3.0-win-x64.zip`。

## 主要功能

- 终末地：官服 / Bilibili 服，Steam App ID `4732690`。
- 鸣潮：新版 3.x 国服库洛启动器；Steam 名称为 [Wuthering Waves](https://store.steampowered.com/app/3513350/Wuthering_Waves/)，App ID `3513350`。
- 两款游戏都可选择“官方启动器”或“QAQR（Mod 管理器）”，各自保存启动方式和 QAQR 路径。旧配置继续使用官方启动器。
- 打开工具后切换游戏、检查路径，也可“一键设置 / 同步两款”。批量操作先检查两款游戏，再正常退出并重启一次 Steam。
- 由 Steam 打开原始启动器；在启动器中手动更新、登录并点击“开始游戏”。工具没有自动点击或网页调试功能。
- 桥接进程跟踪真实游戏，让 Steam 保持运行状态和时长统计。官方启动器模式沿 Steam 正常进程链传递叠加层和截图，需 Steam 与客户端权限一致。
- 每款游戏独立保存配置、备份、计划任务和运行记录；撤回其中一款不会撤回另一款。

## 简单使用

1. 登录 Steam，将要玩的游戏免费添加到库；先用国服启动器安装、更新并登录游戏。
2. 退出游戏和启动器（包括托盘），以管理员身份运行 `steam-bridge.exe`。
3. 切换“终末地 / 鸣潮”确认路径；终末地可选择官服或 Bilibili 服。鸣潮选择启动器根目录的 `launcher.exe` 和游戏目录的 `Wuthering Waves.exe`。
4. 点击“设置当前游戏”，或在两款均检测就绪后点击“一键设置 / 同步两款”。等待 Steam 重启后，从各自官方条目打开启动器，再手动点击“开始游戏”。

撤回时选择对应游戏，再点击“撤回当前游戏”，会恢复首次设置前的安装记录和启动选项。切换终末地服务器也请先撤回。0.2.x 安装需先撤回，再使用新版设置。

## 使用 QAQR

在“启动方式”选择“QAQR（Mod 管理器）”，选择安装目录中的稳定入口 `QAQ-Revival.exe`，确认“客户端”与 QAQR 中该游戏的真实 EXE 路径一致，再点击“设置当前游戏”或“应用设置 / 同步版本”。仅切换界面选项不会更改已有 Steam 配置。从 Steam 开始后，在 QAQR 中手动选择终末地或鸣潮并点击启动；工具不传递游戏启动参数，也不自动点击。

QAQR 有实际 Mod 加载能力，游戏加载方式由 QAQR 自身设置决定。Bridge 只读取其共享配置中的游戏路径，默认使用 `%APPDATA%/QAQ-Revival`，尊重 `QAQM_USER_DATA`，不更改随机启动设置、用户数据或 Mod。

QAQR 独立运行，避免 Steam 停止时终止共享管理器或其他游戏。已经打开时通过稳定入口唤醒现有实例；随机名 EXE 使用其 runtime 标记和文件哈希识别，支持稳定入口退出后的重启交接。Bridge 只跟踪所选游戏的真实 EXE，游戏结束后即结束计时，不等待 QAQR 关闭。同一时间只允许一个 QAQR 桥接会话。

**QAQR 模式不传递 Steam 原生叠加层；Steam“停止”只结束桥接计时。** 游戏需手动退出，QAQR 和其他游戏保持运行。这一限制同样适用于从别处预先打开的 QAQR。

## 是否修改游戏或 Steam

Bridge 本身不改写原始国服的 EXE、DLL、资源或配置，不修改 Steam 的 EXE / DLL，也不向游戏注入代码。官方启动器或 QAQR 仍会按各自流程更新游戏、保存设置或加载 Mod。

工具会修改 Steam 的 `appmanifest_<appid>.acf` 和当前账号该游戏的 `LaunchOptions`，并注册一个用于官启会话清理或独立打开 QAQR 的计划任务。没有修改二进制并不代表官方认可，无法承诺零封号风险。

自己的 EXE 始终位于工具数据目录的 `app/steam-bridge.exe`。Steam 在处理自定义启动命令前会检查默认游戏 EXE 是否存在，因此独立 Steam 目录里会保存真实游戏启动文件的原样副本；这不是改名伪装的桥接程序，也不会把 Steam 更新指向原始国服目录。实际启动命令调用 `steam-bridge.exe`，再由它启动已安装的国服启动器。

为兼容旧版，工具数据继续放在 `%LOCALAPPDATA%/EndfieldSteamBridge`；鸣潮位于其 `wuthering-waves` 子目录。原始 Steam 安装记录和启动选项在首次设置时备份，重复同步不会覆盖首次备份。

## 游戏更新

国服更新继续在原始启动器里进行，通常不用重新设置桥接。Steam 侧更新不由工具自动后台拦截：如果库页面提示更新，先打开该游戏库页面刷新元数据，再打开工具点击“应用设置 / 同步版本”或“一键设置 / 同步两款”。此操作刷新 Steam 版本记录和真实启动文件副本，无需先撤回。

若 Steam 已开始更新，先在 Steam 中暂停下载、正常退出，再进行同步。不要在启用桥接时验证 Steam 游戏文件完整性，否则 Steam 可能向独立目录下载国际服；原始国服目录不受影响。若 Steam 默认启动路径发生变化，工具会要求先撤回再设置。

同步使用本机 Steam 的最新缓存，不保证缓存已获取服务器最新版本。批量操作若后一个游戏失败，已成功的游戏保持有效，界面会报告已完成项，可重试未完成项。

适用于 Windows 10/11 x64，需要 .NET Framework 4.8。Steam 也需以管理员身份运行。

## 构建与验证

运行 `build.ps1` 生成 `dist/steam-bridge.exe`；`test.ps1` 检查渠道识别、双游戏状态隔离、版本同步和撤回；`package.ps1` 生成二进制包、源码包与 SHA256。程序和测试均不需要 Node.js。
